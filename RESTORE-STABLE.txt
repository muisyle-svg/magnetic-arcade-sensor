MAGNETIC ARCADE GUARD — STABLE PRE-STORY-MODE RELEASE

This folder contains the last known-good version from before Story Mode,
Normal Mode, the Sonic CD cinematic, and the progressive energy meter were
added.

To restore it on the arcade PC:

1. Close any running Magnetic Arcade Guard.
2. Copy MagnetArcadeGuard.exe and guard-config.json from this folder to the
   arcade guard folder, replacing the newer copies.
3. Upload magnet_test.ino only if the ESP32 has already been updated with the
   newer Story Mode energy-meter firmware.
4. Start MagnetArcadeGuard.exe normally.

This release is self-contained. The arcade PC does not need Python.
